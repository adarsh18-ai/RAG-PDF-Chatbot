
# 📄 RAG PDF Chatbot using Gemini AI, Hugging Face & FAISS

This project is a Retrieval-Augmented Generation (RAG) based PDF Chatbot that enables users to upload PDF documents and ask questions in natural language. The system performs semantic search using Hugging Face Sentence Transformers and FAISS, then generates context-aware responses using Google Gemini AI.

The chatbot combines Large Language Models (LLMs), Vector Databases, and Semantic Search to provide accurate and document-grounded answers.

---

## Features

* Upload PDF documents
* Automatic text extraction
* Intelligent text chunking
* Semantic search using FAISS
* Hugging Face Sentence Transformer embeddings
* Context-aware question answering
* Google Gemini AI integration
* Interactive Streamlit interface
* Retrieval-Augmented Generation (RAG)

## Usage

1. Launch the Streamlit application.
2. Upload a PDF document.
3. Wait for document processing.
4. Enter your question.
5. Receive context-aware answers generated from the PDF content.
